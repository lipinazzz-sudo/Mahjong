# Sapi/Gu audio assets

Folder khusus audio Sapi/Gu. Audio Mahjong tetap berada di `/audio` dan tidak digunakan oleh game ini.

Nama file yang disiapkan untuk tahap integrasi audio:
- `bgm-lobby.mp3` — musik halaman depan/lobby.
- `bgm-game.mp3` — musik saat bermain.
- `sfx-card-deal.mp3` — efek pembagian kartu.
- `sfx-bet.mp3` — efek chip/taruhan.
- `sfx-fold.mp3` — efek fold.
- `sfx-show.mp3` — efek saat Show.
- `sfx-win.mp3` — efek ronde dimenangkan.

File audio belum disertakan. Kontrol volume dan audio pada halaman Sapi/Gu saat ini hanya menyimpan preferensi; pemutaran akan dihubungkan ketika berkas audio khusus sudah tersedia.
