MAJONG DJ - AUDIO
===================

Put this folder next to index.html on GitHub:

/
├── index.html
└── audio/
    ├── bgm-game.mp3
    ├── sfx-draw.mp3
    ├── sfx-discard.mp3
    ├── sfx-chi.mp3
    ├── sfx-pon.mp3
    ├── sfx-kan.mp3
    ├── sfx-ron.mp3
    ├── sfx-tsumo.mp3
    └── sfx-button.mp3

The HTML loads these files with relative paths.
No external audio host is required.

Audio controls:
- Music Volume: 0-100%
- SFX Volume: 0-100%
- Audio ON/OFF: global mute
